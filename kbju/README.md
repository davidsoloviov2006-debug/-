# КБЖУ — дневник питания

Бесплатное приложение для подсчёта калорий и БЖУ, как FatSecret, но с функциями «Премиум» бесплатно. Работает на iPhone как обычное приложение (иконка на главном экране, полный экран, офлайн). Все данные хранятся только на телефоне.

## Возможности
- **Сканер штрихкода** → сразу КБЖУ (база Open Food Facts, в том числе израильские товары 729…).
- Товара нет в базе → **фото таблицы питательности** (иврит/английский/русский) → поля заполняются автоматически, продукт сохраняется по штрихкоду и в следующий раз находится сразу.
- Национальная база питания Минздрава Израиля (מאגר התזונה הלאומי, ~4 500 продуктов с брендами: ברמן, אנג'ל, ודש, תנובה…) + встроенная база (~230 блюд на 3 языках) + Open Food Facts + свои продукты и рецепты.
- История как в FatSecret: последняя порция и «+» в одно нажатие; серия дней подряд.
- Дневник по приёмам пищи, «как вчера», вода, активность, заметки.
- Калькулятор нормы, цели по калориям, БЖУ, клетчатке и воде.
- Отчёты за 7/30/90 дней, баланс БЖУ, топ продуктов, экспорт CSV.
- Вес с графиком и прогнозом, интервальное голодание.
- Apple «Здоровье» через «Команды»: еда уходит в «Здоровье», обратно приходят активные калории с Apple Watch, шаги и вес (инструкция: Профиль → Apple «Здоровье»).
- Русский, иврит, английский. Тёмная и светлая темы в стиле Liquid Glass.
- Резервная копия и восстановление (JSON).

## Установка на iPhone
1. Откройте ссылку на приложение в **Safari**.
2. Нажмите «Поделиться» → **«На экран Домой»**.

## Публикация (один раз)
GitHub → Settings → Pages → Source: **GitHub Actions**. После слияния в `main` приложение будет доступно по адресу `https://<user>.github.io/<repo>/`.

## Локальный запуск
```
cd kbju && python3 -m http.server 8000
```

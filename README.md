# limit-bars

Плагин Claude Code: полоски лимитов 5-часового и недельного плана над полем ввода (работает в приложении, в том числе на телефоне).

## Установка

```
/plugin marketplace add davidsoloviov2006-debug/-
/plugin install limit-bars@limit-bars
```

Нужна подписка Pro/Max: без неё данных о лимитах нет, и полоски не показываются.

Статус-строка для терминала лежит отдельно: `.claude/statusline.sh`.
